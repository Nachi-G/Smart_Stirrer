# Product Requirements

## Verification

Every engineering requirement should eventually specify a verification method.

Verification methods:

- ANALYSIS
- SIMULATION
- BENCH TEST
- COOKING TEST
- INSPECTION
- USER TEST

## User-level requirements



R-001
The system shall stir food without continuous manual user intervention.

R-002
The system shall work with multiple commonly used cooking vessels.

R-003
The system shall not require the user to permanently modify cookware.

R-004
Food-contact components shall be removable or otherwise practical to clean.

R-005
The system shall tolerate the thermal environment above a stovetop cooking vessel.

R-006
The system shall detect or safely respond to conditions that could damage
the mechanism, utensil, cookware, or food.

R-007
Setup time shall be sufficiently low that using the system provides a net
convenience benefit.
